# OTUS Booking Room Frontend

Веб-приложение для бронирования переговорных комнат.

## Описание

Это фронтенд для сервиса бронирования комнат, реализованный на React + TypeScript с использованием Material UI. Позволяет:
- Просматривать список доступных переговорных комнат
- Фильтровать комнаты по дате и вместимости
- Бронировать выбранную комнату на нужное время
- Просматривать свои бронирования

## Быстрый старт

1. Установите зависимости:

```bash
npm install
```

2. Запустите приложение в режиме разработки:

```bash
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

> ⚠️ Для работы требуется запущенный backend на http://localhost:8080 (см. OpenAPI docs.yaml)

## Структура проекта

- `src/components` — основные React-компоненты (список комнат, форма бронирования и др.)
- `src/services/api.ts` — сервис для работы с API
- `src/types/api.ts` — типы данных, соответствующие OpenAPI
- `public/` — статические файлы

## Основные команды

- `npm start` — запуск в режиме разработки
- `npm run build` — сборка production-версии
- `npm test` — запуск тестов

## Пример использования

1. Откройте приложение
2. Выберите дату и вместимость для поиска комнат
3. Нажмите "Забронировать" напротив нужной комнаты
4. Заполните форму и подтвердите бронирование
